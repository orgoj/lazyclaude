## Design Decisions

### Exception Handling Architecture
**Decision**: Override `_handle_exception()` instead of creating custom exception wrapper
**Why**: Textual's official exception handling mechanism - integrates properly with framework's event loop and provides Rich traceback rendering

### Source Field Type Flexibility
**Decision**: Support both `str` and `dict[str, Any]` for plugin source field
**Why**: Marketplace format evolved over time - some use simple strings, others use `{"source": "url", "url": "..."}` structure. Need backward compatibility.

### Description Priority Chain
**Decision**: Load description with priority: `marketplace.json` root → `metadata.description` → `known_marketplaces.json`
**Why**: Format evolved - older marketplaces use root level, newer use metadata nesting. Fallback ensures compatibility.

### Helper Function Location
**Decision**: Place `extract_source_url()` in `models/marketplace.py` as module-level function
**Why**: Shared across UI layer (widgets) and business logic (mixins) - models module is neutral dependency location

## Lessons Learned

### Technical Lessons:

**Textual Exception Handling**:
- Override `_handle_exception(error: Exception)` for app-wide exception handling
- Call `super()._handle_exception(error)` to get Rich traceback rendering
- Custom `_fatal_error()` overrides break Textual's built-in error display
- Exceptions in event handlers are caught by Textual's event loop

**Union Types with Type Guards**:
```python
# Type hint allows both
source: str | dict[str, Any]

# Runtime extraction with isinstance check
if isinstance(source, dict):
    url = source.get("url")
    return str(url) if url is not None else str(source)
return source
```

## Code Patterns Used

### Exception Handling Pattern (Textual):
```python
def _handle_exception(self, error: Exception) -> None:
    """Override Textual's exception handler."""
    # Custom logging
    if self.debug_mode:
        logger.error(f"Exception: {error}")

    # Always stderr
    traceback.print_exc(file=sys.stderr)

    # Call parent for framework integration
    super()._handle_exception(error)
```

### Union Type Normalization:
```python
def extract_source_url(source: str | dict[str, Any]) -> str:
    """Extract URL from flexible format."""
    if isinstance(source, dict):
        url = source.get("url")
        return str(url) if url is not None else str(source)
    return source
```

### Priority Chain Pattern:
```python
description = (
    mp_root_metadata.get("description")  # Primary
    or mp_root_metadata.get("metadata", {}).get("description")  # Secondary
    or entry_data.get("description")  # Fallback
    or ""  # Default
)
```
